## Context

The VpE script (`Therapy_VpE_202601.sql`) is a ~1000-line, 10-step pipeline that creates intermediate tables sequentially. Each step depends on the previous one. The structure is:

1. **Claims extraction** — 3 entity blocks (COSMOS PR+OP, CSP PR+OP, NICE PR+OP), each with therapy-specific proc_cd/rvnu_cd filters and business exclusions
2. **Stack + population flags** — Union all 3 entity claims, add OAH/CnS_Dual/MnR_Dual/MnR_ISNP/MnR_FFS flags → derive `population`
3. **Aggregate** — Group by visit-level, derive `claim_status` (Paid/Denied) from allowed > 0.01
4. **VpE step 1** — Group by visit, map proc_cd → `mbmserv_dtl` (Chiro/PT-OT/ST/Other)
5. **VpE step 2** — `lag()` window to compute `visit_day_diff`, `ep_flag` (>30 days = new episode)
6. **VpE step 3** — Cumulative episode numbering, `ep_start_dt`
7. **Episodes summary** — Aggregate episode counts by dimensions
8. **Visits summary** — Aggregate visit counts, allowed, paid, mbr_count by dimensions + runout months
9. **Stack visits + episodes** → final `knd_mbm_vpe_summary`
10. **Extract** — Remove `population = 'NA'`
